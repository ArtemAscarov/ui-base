01 — form

Checkbox

A real input stays in the form and keeps the keyboard; the box beside it is what you style. Indeterminate is set from markup and cleared by the browser on first click.

checked / disabled

boolean
onChange

03 — overlay

Select

A listbox that behaves like the native one: arrows move, letters jump to a match, repeating a letter cycles through it, and disabled options are skipped rather than focused.

Markup

Value written to the hidden input
data-selected
Option shown on first paint
select:change
Bubbling event, value in detail

React props

options
{ value, label, disabled }[]
value / defaultValue
Controlled or uncontrolled

Tokens

  • --select-width300px
  • --select-list-max-height240px
  • --select-duration200ms

05 — motion

Marquee

Speed is set in pixels per second, not seconds per loop, so two words and twenty words travel at the same pace. The script fills the ribbon with as many copies as the width needs.

60 px per second

Pauses on hover

Markup

data-direction
"reverse" flips the travel
data-pause-on-hover
"false" keeps it running

React props

speed
Pixels per second, default 60
children
Repeated to fill the ribbon

Tokens

  • --marquee-speed60
  • --marquee-tilt-3deg
  • --marquee-gap64px

06 — motion

Carousel

A copy of the strip sits on each side, so the loop never hits an end. Drag it, use the arrow keys, or press the buttons faster than it animates — the clicks queue instead of dropping.

Drag me
Arrow keys work
